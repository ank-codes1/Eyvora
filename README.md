# EYVORA

AI Driver Monitoring and Emergency Response System.

## Current V1 features
- Face detection
- Eye open/closed detection
- Blink counting
- Yawn detection
- Head direction
- Drowsiness detection
- SQLite event logging

## Planned hardware
- ESP32
- MAX30102
- MLX90640
- EDA/GSR sensor
- Pressure sensor
- Buzzer
- Cancel button
- Hazard LEDs
